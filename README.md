# resturant-data-analysis
data analysis for resturant with 5 branches
حللت بيانات 5 فروع لسلسلة مطاعم مصرية خلال 2025 لتحديد أفضل الفروع والأصناف والأوقات.

-	 أبرز النتائج:
• فرع الزمالك  حجمه صغير لكن حقق أعلى هامش ربح رغم أنه مش الأعلى في المبيعات 
• الوردية المسائية تحقق 45% من إجمالي الإيراد اليومي
• الوجبات الرئيسية تقود المبيعات لكن المشروبات الأعلى في هامش الربح
• الجمعة والسبت يمثلان 35% من المبيعات الأسبوعية

-  المهارات المُستخدمة:
SUMIF | AVERAGEIF | SUMPRODUCT | Profit Margin Analysis
